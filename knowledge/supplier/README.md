# 供应商主数据库说明

## 数据文件

`supplier_db.json` —— 结构化供应商风险记录，审核引擎按乙方名称自动匹配：

```json
[
  {
    "name": "供应商名称",
    "credit_code": "统一社会信用代码",
    "legal_rep": "法定代表人",
    "risk": {
      "level": "高风险|中风险|低风险",
      "flags": ["失信被执行人", "1条行政处罚记录", "..."],
      "source": "数据来源（中国执行信息公开网/国家企业信用信息公示系统等）",
      "checked_at": "核验日期"
    }
  }
]
```

命中规则：乙方名称与记录名称互相包含即命中；含"失信被执行人/经营异常/吊销执照"
标记的按**刚性不通过**处理（暂停签约流程）。

## 核验要点（审核必查维度）

1. **主体存续**：名称、统一社会信用代码、注册地址、法定代表人、经营状态（存续/注销/吊销）；
2. **资质许可**：行业许可证、专业资质等级是否覆盖合同标的；
3. **信用风险**：失信被执行人、经营异常名录、行政处罚、重大诉讼；
4. **历史合作**：履约评价、争议记录（对接内部合同管理系统获取）。

## 数据来源（官方渠道）

- 国家企业信用信息公示系统：https://www.gsxt.gov.cn/
- 中国执行信息公开网（失信被执行人）：https://zxgk.court.gov.cn/
- 中国裁判文书网：https://wenshu.court.gov.cn/
- 商业 API（企业级）：天眼查、企查查等

## P1 升级路线

当前为本地库匹配模式。升级方案：审核时按乙方统一社会信用代码调用
企业信用信息公示系统/商业 API 实时核验，结果自动回写 `supplier_db.json`
并触发"供应商资信风险"规则（履约能力风险维度）。
